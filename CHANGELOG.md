# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres
to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v26.2.3-mc26.2.x] - 2026-09-06

### Fixed

- Remove the `minecraft:custom_name` component when the name tag name is unchanged

## [v26.2.2-mc26.2.x] - 2026-09-03

### Added

- Add config options for controlling when shearing off a name tag is not possible
- By default, this allows, e.g., shearing wool off a sheep before removing an applied name tag

## [v26.2.1-mc26.2.x] - 2026-08-31

### Changed

- Improve selecting individual characters using the mouse in an edit box

### Fixed

- Fix crash when dragging the mouse to the left side of an edit box while selecting text
- Fix rendering wrong selection highlight when selecting bold text in an edit box

## [v26.2.0-mc26.2.x] - 2026-06-18

### Changed

- Update to Minecraft 26.2.x
